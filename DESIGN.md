## World

Calm venue social. Logo-locked terracotta: cream `#FCF3E8`, flame `#D05927`, rust `#993818` (sampled from `assets/images/icon.png`). System type. No dating chrome, no glass, no extra display face.

## Tokens

Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 (`theme/space`)
Radius: 12 / 16 / 24 / pill (`theme/radius`)
Type: display Georgia/serif 34/400, title 22/700, body 16/400, caption 13/400
Signature: the flame icon from `assets/images/icon.png` as the brand mark, not a generic wordmark.
Accent: `#D05927` (logo flame). Headings/ink: `#993818`. Page ground: `#FCF3E8`.
Elevation: tinted offset shadow, not a 1px costume border

## Components

Primary actions: 52pt, 16 radius, press scale 0.96
Cards: 24 radius, 16 padding (concentric inner 12)
Avatars: 1px black/white 10% outline
Timers: tabular-nums
Tabs: outline idle, fill when selected
Empty states: icon well + title + body + optional CTA
