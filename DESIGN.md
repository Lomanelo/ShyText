# Design

<!-- impeccable:design-schema 1 -->

## Platform

adaptive

## Mode

Operate

## World

Native venue social. System grouped backgrounds and labels. One brand tint: flame `#D05927` from the mark. System type. No Georgia, no cream-paper feed, no dating chrome, no glass.

## Tokens

Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 (`theme/space`)
Radius: 12 / 16 / 24 / pill, `borderCurve: continuous` (`theme/radius`)
Type: iOS text styles — display 34/700, title 22/600, headline 17/600, body 17/400, caption 13/400
Signature: flame mark + lowercase shytext wordmark; flame tint on actions and selected tabs
Accent: `#D05927`. Surfaces: `systemGroupedBackground` / Material dynamic background. Cards: secondary grouped / surfaceContainer
Elevation: `boxShadow` 0 8 24, not a costume border

## Components

Primary actions: 52pt, 16 radius, press scale 0.96, `onAccent` white
Cards: 24 radius, 16 padding
Avatars: 1px 10% black outline
Timers: tabular-nums
Tabs: system tab bar, outline idle / fill selected, flame tint
Empty states: icon well + title + body + optional CTA
Settings: grouped inset rows with chevron
Navigation: native stack headers; no custom Back labels
