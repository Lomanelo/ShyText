# shytext

Say something to the room without having to approach the room.

Venue icebreaker. Check in, leave a short ShyText, say hello. Chat starts only if the author accepts. Exact GPS is never shown to other users.

This is an Expo SDK 57 development-client app. Do not use Expo Go.

```bash
npm install
cp .env.example .env
npx expo start --dev-client
```

Full setup, Firebase, Places, EAS, and the two-phone test plan: [SETUP.md](SETUP.md)
